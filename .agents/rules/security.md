# Instructions
AIがコードを生成および修正する際は、以下のセキュリティ要件を必ず遵守すること。

- **シークレット管理**: APIキーやパスワードをコード内にハードコードしない。必ず `.env` などの環境変数を使用する。
- **DB操作 (SQLインジェクション対策)**: 必ずSQLAlchemyのORMまたはパラメータ化クエリを使用し、生のSQL文字列結合を行わない。
- **XSS対策 (React)**: ユーザー入力を描画する際、原則として `dangerouslySetInnerHTML` を使用しないこと。
- **CORS設定 (FastAPI)**: 開発時を除き、本番環境を見据えてCORSの許可オリジンを `*` ではなく明示的に指定すること。
- **パスワード保存**: ユーザーのパスワードは絶対に平文で保存せず、必ず安全なハッシュ関数でハッシュ化すること。
