# Instructions
- Always respond in **Japanese.**
- Created or modified code comments and documentation strings must be written in **Japanese.** (variable and function names should remain in English)
- Follow the user's coding style but prioritize safety.
- ローカル環境での動作確認やコマンド実行、パッケージのインストールを行う際は、原則として仮想環境（venvなど）や Docker を使用してください。グローバル環境に直接インストールや実行を行わないでください。
- 作業を開始し、新しくブランチを作成する際は、必ずベースブランチ（`main`など）に移動して最新の状態を `pull` してからブランチを切るようにしてください。（コンフリクトを未然に防ぐため）
- 実作業（コード修正やコマンド実行など）を開始する前には、必ず対象となるタスクの GitHub Issue を起票し、タスクの目的を明確にしてから進めるようにしてください。
