# 🚨 CRITICAL INSTRUCTION (AI WORKFLOW ENFORCEMENT) 🚨
AI（私）がこのプロジェクトで作業を行う際は、いかなるコード編集を行うよりも**絶対に先に**以下のチーム開発ワークフローを遵守すること。
もしこれを無視して main ブランチのままファイルを編集しようとした場合、システムフックによって強制ブロックされます。

- **作業管理**: 全てのタスクはIssueベースで管理される想定で動くこと。
- **タスクの初期化 (CRITICAL MUST)**: 新しい作業の依頼を受けた場合、いかなるコード編集やコマンド実行を行うよりも**先に**、ユーザーに `/start` コマンド（`task-init` スキル）の実行を促すか、もしくはAI自身が GitHub CLI (`gh`) などを通じてIssueの起票と作業ブランチの作成を完了させること。
- **ブランチ作成**: `main` ブランチに直接コミットしないこと。新しい機能や修正を行う際は、必ず新しいブランチを切ってから作業を開始すること。
- **PR作成まで**: AIの担当範囲は「コードの作成、テスト、サブエージェントによるコードレビュー、コミット、そしてPull Requestの作成」までとする。
- **AIによる事前レビュー**: Pull Requestを作成する前に、必ずコードレビュー用のサブエージェント（レビュアー役）を呼び出して実装の品質や妥当性をレビューさせること。指摘事項がある場合は修正を行った上でPRを作成すること。
- **マージ権限**: AIは決してPRをマージしてはいけない。マージは必ず人間（ユーザー）のレビューとApproveを経て行われる。
