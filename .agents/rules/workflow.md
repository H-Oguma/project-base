# Instructions
このプロジェクトにおいてAI（私）が作業を行う際は、以下のチーム開発ワークフローを厳格に遵守すること。

- **作業管理**: 全てのタスクはIssueベースで管理される想定で動くこと。
- **ブランチ作成**: `main` ブランチに直接コミットしないこと。新しい機能や修正を行う際は、必ず新しいブランチを切ってから作業を開始すること。
- **PR作成まで**: AIの担当範囲は「コードの作成、テスト、コミット、そしてPull Requestの作成」までとする。
- **マージ権限**: AIは決してPRをマージしてはいけない。マージは必ず人間（ユーザー）のレビューとApproveを経て行われる。
