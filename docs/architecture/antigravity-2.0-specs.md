# Antigravity 2.0 仕様

Antigravity 2.0 は、IDEから独立してエージェントのアクティビティを起動・監視できるデスクトップ Electron アプリケーションです。エージェントのアクティビティをオーケストレーションするための統合プラットフォームを提供します。

## 1. 統合インターフェース

### 左側サイドバー (Left-hand Sidebar)

- **New Conversation (新規会話)**: エージェントとの新しいチャットセッションを開始します。
- **Projects (プロジェクト)**: 異なるワークスペースやリポジトリを管理し、切り替えます。
- **Scheduled Tasks (スケジュール化されたタスク)**: 定期的なバックグラウンドタスク (cron) や一度きりの遅延タイマーを定義、監視、実行します。
- **Skills & Customizations (スキルとカスタマイズ)**: アクティブなスキル、ルール、プラグイン、および MCP サーバーを表示、管理します。
- **Settings (設定)**: アプリケーションの環境設定、モデルの選択、および権限を設定します。

### チャットキャンバス (Chat Canvas)

エージェントとの直接的な対話、計画、およびタスク実行のためのメインパネルです。

- **スラッシュコマンド (Slash Commands)**: `/` と入力して組み込みのワークフローを呼び出します。専用のサブエージェントを起動するなど、特定のエージェントの振る舞いをトリガーします。
- **@ メンション (@ Mentions)**: `@` と入力してメンションメニューを開き、メッセージにコンテキスト（ファイル、フォルダ、以前の会話、ターミナルセッション、ルール、MCPサーバー/ツールなど）を直接添付します。
- **メディアのアップロード (Media Uploads)**: 画像やファイルをドラッグ＆ドロップするか、チャットキャンバスに貼り付けてエージェントと共有します。

## 2. エージェント設定と権限

**Settings (設定)** サイドバーでは、エージェントの振る舞い、セキュリティ、権限に関するグローバルおよびプロジェクトレベルの制御を提供します。

### グローバル設定

すべてのプロジェクトと会話に適用される設定です：

- **モデルの選択 (Model Selection)**: アクティブなGeminiモデルを選択します。
- **ツール実行ポリシー (Tool Execution Policy)**: ターミナルコマンドの実行前に承認を要求するかどうかを制御します。
- **ターミナルサンドボックス (Terminal Sandbox)**: セキュリティ向上のため、制限されたサンドボックス環境内でエージェントのコマンドを実行します。
- **ワークスペース外ファイルアクセス (Non-Workspace File Access)**: エージェントが現在のワークスペースルート外のファイルを読み書きできるかを制御します。
- **インターネットアクセス (Internet Access Policy)**: ネットワークリクエストの許可/拒否を制御します。
- **アーティファクトレビューモード (Artifact Review Mode)**: エージェントがアーティファクトのレビューを要求するタイミングを制御します。
- その他、コマンドの許可/拒否リスト、ブラウザの許可リストなどの設定があります。

### プロジェクトレベル設定

各プロジェクトはグローバル設定のサブセットを上書きできます。プロジェクトがアクティブな場合、これらの設定がグローバル設定より優先されます。

- **ファイルアクセスポリシー**
- **インターネットアクセスポリシー**
- **サンドボックスモード**
- **自動実行ポリシー**
- **アーティファクトレビューモード**
- **権限付与 (Permission Grants)**: プロジェクトのワークスペース内でのみ適用される権限を定義します。
